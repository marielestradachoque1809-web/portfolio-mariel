# Portfolio personal — Mariel Estrada Choque

Sitio web estático desarrollado como trabajo final del Módulo 1.

## Páginas

- Inicio: presentación personal y áreas de interés.
- Proyectos: portfolio académico e ideas a futuro.
- Contacto: enlaces de contacto y formulario visual (sin envío).

## Tecnologías

HTML5, CSS3 y Bootstrap 5.3.8. Navegación adaptable sin JavaScript propio. Incluye ilustraciones en SVG, un audio breve de bienvenida y un boceto del sitio en `prototipo/boceto.svg`.

## Publicación

El archivo principal es `index.html`. GitHub Pages debe publicar desde la rama `main`, carpeta raíz (`/`).

Una vez publicado, agregar el enlace de GitHub Pages en el campo **Website** de la sección **About** del repositorio y en el documento `docs/README.md`. Para la entrega del curso, copiar el enlace al repositorio en el aula virtual.

## Estructura

```text
index.html
pages/
  proyectos.html
  contacto.html
css/
  styles.css
assets/
  images/
    ilustracion-web.svg
    ilustracion-proyecto.svg
  audio/
    sonido-inicio.wav
prototipo/
  boceto.svg
docs/
  README.md
```

El audio de bienvenida puede no reproducirse automáticamente en todos los navegadores, porque algunos bloquean la reproducción automática con sonido.
